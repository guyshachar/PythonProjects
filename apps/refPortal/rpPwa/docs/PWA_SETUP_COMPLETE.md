- **תיעוד מלא** - מדריך שימוש מפורט

## 🚀 השלבים הבאים

### 1. הגדרת VAPID Keys
```bash
cd rpApi/static/pwa
chmod +x setup-pwa.sh
./setup-pwa.sh
```

זה ייצור:
- VAPID keys חדשים
- קובץ `pwa-config.js` מעודכן
- דוגמאות שרת להתראות דחיפה

### 2. עדכון הגדרות השרת
עדכן את השרת שלך להשתמש ב-VAPID keys החדשים:

```javascript
// בשרת Node.js
const webpush = require('web-push');
webpush.setVapidDetails(
  'mailto:your-email@domain.com',
  'YOUR_VAPID_PUBLIC_KEY',
  'YOUR_VAPID_PRIVATE_KEY'
);
```

### 3. בדיקת ה-PWA
פתח את הדפים הבאים בדפדפן:

- **`pwa-validation.html`** - בדיקה מקיפה של כל התכונות
- **`refportal-pwa.html`** - האפליקציה הראשית
- **`pwa-test.html`** - בדיקה בסיסית

### 4. בדיקת התקנה
1. פתח את ה-PWA בדפדפן
2. לחץ על כפתור ההתקנה (אם מופיע)
3. או השתמש בתפריט הדפדפן: "התקן אפליקציה"

## 🔧 הגדרות נוספות

### עדכון API Endpoints
עדכן את הכתובות ב-`pwa-config.js`:

```javascript
API_BASE_URL: 'https://your-actual-api-domain.com',
ENDPOINTS: {
    DASHBOARD: '/api/your-dashboard-endpoint',
    // ... עדכן את כל הכתובות
}
```

### התאמה אישית
- **צבעים** - עדכן ב-`refportal-pwa.css`
- **לוגו** - החלף קבצי תמונה ב-`images/`
- **תוכן** - ערוך את הטקסטים ב-HTML
